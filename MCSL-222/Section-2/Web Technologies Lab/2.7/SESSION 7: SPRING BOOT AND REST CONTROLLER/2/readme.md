The application.properties file located in the src/main/resources folder. Spring Boot's auto-configuration detects these properties and automatically sets up the DataSource and EntityManager.

Configuration File: src/main/resources/application.properties

Here is the complete configuration for a MySQL database.

```properties```
```
# ===============================
# DATABASE CONNECTION SETTINGS
# ===============================
# The JDBC URL. Replace 'IGNOU_Admission' with your actual database name.
spring.datasource.url=jdbc:mysql://localhost:3306/IGNOU_Admission?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC

# Database Username
spring.datasource.username=root

# Database Password
spring.datasource.password=your_password

# The Driver Class Name (Optional in newer Spring Boot versions as it's auto-detected, but good practice)
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# ===============================
# JPA / HIBERNATE SETTINGS
# ===============================
# Automatically updates the schema (tables) when the application starts.
# Options: none, validate, update, create, create-drop
spring.jpa.hibernate.ddl-auto=update

# Displays the SQL queries generated by Hibernate in the console (useful for debugging)
spring.jpa.show-sql=true

# Formats the SQL in the console to make it readable
spring.jpa.properties.hibernate.format_sql=true

# Explicitly sets the SQL dialect (helps Hibernate generate optimized SQL for MySQL 8)
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQL8Dialect

```

Explanation of Key Properties:

* spring.datasource.url: Defines where your database lives. The ?useSSL=false parameter disables SSL warnings for local development.
* spring.jpa.hibernate.ddl-auto=update: This is very useful for development. It checks your Java Entities (like Student.java) and updates the database table columns to match them without deleting your data.
* spring.jpa.show-sql=true: Prints every database operation to your console, allowing you to verify that your JPA repositories are working correctly.
