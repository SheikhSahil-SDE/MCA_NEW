# 12. Show the pcap traces at node n2’s Wi-Fi interface.


We are required to capture and visualize the actual packets being received by node $n2$. In a wireless simulation, the .pcap files contain detailed information about the 802.11 frames, including signal strength and MAC headers.

Step-by-Step Instructions

1. Enable Pcap Tracing: In your C++ script, you must explicitly tell the YansWifiPhyHelper to capture packets on the wireless interface of node $n2$.
2. Run the Simulation: Execute the script using ./waf. This will generate a file (e.g., wifi-n2-trace-5-0.pcap).
3. Open in Wireshark: Launch Wireshark and open this specific file to see the traffic from the perspective of $n2$.

C++ Code for Pcap Capture

Add this line to your code before the Simulator::Run() command to target node $n2$ specifically:

C++

// 0 is node n1, 1 is node n2 (the receiver)
wifiPhy.EnablePcap ("wifi-n2-trace", devices.Get(1)); 


What to Look for in the TracesOnce you open the file in Wireshark, look for these specific details to include in your lab record:

* 802.11 Management Frames: You will likely see "Beacon" frames or "Probe Requests" if you have a complex setup, but in an ad-hoc network, you'll primarily see Data and Control frames.

* Source and Destination IPs: Filter by ip.addr == 10.1.1.2 (or your assigned IP for $n2$) to see the UDP packets arriving from $n1$.

* Radio Tap Header: Wireless traces include a "Radio Tap" header that shows the RSSI (Received Signal Strength Indication). Since this is a mobile ad-hoc network (MANET), you can observe how this strength changes if the nodes are moving away from each other .

* UDP Overhead: You can verify the 8-byte UDP header discussed in your MCS-218 textbook, confirming the connectionless nature of the transfer.

Troubleshooting Tips

* Empty Trace: If the pcap is empty, ensure that $n1$ and $n2$ are actually within transmission range of each other during the simulation. Since you are using a mobility model, they may have drifted apart before the application started.

* File Naming: The filename usually follows the format [prefix]-[node_index]-[interface_index].pcap. For node $n2$, look for the index 1.
