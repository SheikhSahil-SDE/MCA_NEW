# 11. Send packets to node n2 from node n1 and plot the number of bytes received with respect to time at node n2.

We will extend the UDP communication script to collect data and visualize the network performance. This task requires capturing the reception of packets at node $n2$ and plotting that data over the simulation duration.

**Step-by-Step Instructions**

1. Configure the Application: Use an OnOffApplication on node $n1$. Unlike a simple echo, this provides a continuous stream of data at a fixed rate, which creates a more meaningful plot.
2. Define a Trace Sink: You must write a small "Callback" function in your C++ code. This function will trigger every time node $n2$ receives a packet, recording the current simulation time and the total bytes received.
3. Data Output: Direct the output of your trace sink to a .dat or .txt file (e.g., bytes_over_time.dat).
4. Plotting: Use a tool like Gnuplot or Excel to read the generated file and create the graph.

**C++ Code Implementation**
Save this code as plot_bytes.cc in your scratch folder.

```C++```
```
#include "ns3/core-module.h"
#include "ns3/network-module.h"
#include "ns3/internet-module.h"
#include "ns3/point-to-point-module.h"
#include "ns3/applications-module.h"

using namespace ns3;

// Global variable to track cumulative bytes
uint32_t totalBytesReceived = 0;

// Trace Sink: This function runs every time a packet is received
void PacketReceivedTrace(Ptr<OutputStreamWrapper> stream, Ptr<const Packet> packet, const Address &address)
{
    totalBytesReceived += packet->GetSize();
    *stream->GetStream() << Simulator::Now().GetSeconds() << "\t" << totalBytesReceived << std::endl;
}

int main(int argc, char *argv[])
{
    NodeContainer nodes;
    nodes.Create(2);

    PointToPointHelper p2p;
    p2p.SetDeviceAttribute("DataRate", StringValue("5Mbps"));
    p2p.SetChannelAttribute("Delay", StringValue("2ms"));

    NetDeviceContainer devices = p2p.Install(nodes);

    InternetStackHelper stack;
    stack.Install(nodes);

    Ipv4AddressHelper address;
    address.SetBase("10.1.1.0", "255.255.255.0");
    Ipv4InterfaceContainer interfaces = address.Assign(devices);

    // Receiver on n2
    uint16_t port = 9;
    PacketSinkHelper sink("ns3::UdpSocketFactory", InetSocketAddress(Ipv4Address::GetAny(), port));
    ApplicationContainer sinkApp = sink.Install(nodes.Get(1));
    sinkApp.Start(Seconds(1.0));
    sinkApp.Stop(Seconds(20.0));

    // Sender on n1 (Constant Bit Rate)
    OnOffHelper onoff("ns3::UdpSocketFactory", InetSocketAddress(interfaces.GetAddress(1), port));
    onoff.SetAttribute("DataRate", StringValue("1Mbps"));
    onoff.SetAttribute("PacketSize", UintegerValue(1024));
    
    ApplicationContainer clientApp = onoff.Install(nodes.Get(0));
    clientApp.Start(Seconds(2.0));
    clientApp.Stop(Seconds(18.0));

    // Setup the trace file
    AsciiTraceHelper ascii;
    Ptr<OutputStreamWrapper> stream = ascii.CreateFileStream("bytes_received.dat");
    
    // Connect the Trace Sink to the PacketSink Rx trace source
    Config::ConnectWithoutContext("/NodeList/1/ApplicationList/0/$ns3::PacketSink/Rx", 
                                  MakeBoundCallback(&PacketReceivedTrace, stream));

    Simulator::Run();
    Simulator::Destroy();
    return 0;
}
```

**Generating the Plot**
After running the simulation with ./waf --run scratch/plot_bytes, a file named bytes_received.dat will be generated.
To plot this using Gnuplot, enter the following commands in your terminal:

1. Start Gnuplot: gnuplot
2. Set titles: set title "Total Bytes Received vs Time"
3. Label Axes: set xlabel "Time (seconds)", set ylabel "Cumulative Bytes"
4. Plot: plot "bytes_received.dat" using 1:2 with linespoints title "Traffic Flow"

**Observations for Your Lab Record**

* Linear Growth: You should see a straight diagonal line. This is because the OnOffApplication sends data at a constant rate (1Mbps), meaning the total bytes received increases linearly over time.
* Start/Stop Gaps: Notice that the graph starts at $t=2.0$ seconds (when the client starts) and flattens out at $t=18.0$ seconds (when the client stops).
* Network Capacity: Since the link is 5Mbps and the data rate is 1Mbps, there should be zero packet loss, resulting in a smooth, continuous line.
