


We need to configure a basic UDP communication between two nodes. While this sounds similar to Session-1, the focus in Session-5 is usually on data collection and performance analysis.

Step-by-Step Instructions

1. Nodes: Create two nodes ($n1$ and $n2$).
2. P2P Link: Connect them using a PointToPointHelper.
3. Internet Stack: Install the standard stack on both.
4. Server ($n2$): Use the UdpEchoServerHelper or a PacketSink. A PacketSink is better for monitoring total bytes received.
5. Client ($n1$): Use the UdpEchoClientHelper or OnOffApplication to send packets to the server's IP address and port.


**C++ Code Implementation**
Save this code as udp_client_server.cc in your scratch folder.

```C++```
```
#include "ns3/core-module.h"
#include "ns3/network-module.h"
#include "ns3/internet-module.h"
#include "ns3/point-to-point-module.h"
#include "ns3/applications-module.h"

using namespace ns3;

int main (int argc, char *argv[])
{
  // 1. Create 2 Nodes (n1 and n2)
  NodeContainer nodes;
  nodes.Create (2);

  // 2. Physical Link Configuration
  PointToPointHelper p2p;
  p2p.SetDeviceAttribute ("DataRate", StringValue ("5Mbps"));
  p2p.SetChannelAttribute ("Delay", StringValue ("2ms"));

  NetDeviceContainer devices = p2p.Install (nodes);

  // 3. Install Internet Stack
  InternetStackHelper stack;
  stack.Install (nodes);

  Ipv4AddressHelper address;
  address.SetBase ("10.1.1.0", "255.255.255.0");
  Ipv4InterfaceContainer interfaces = address.Assign (devices);

  // 4. Setup UDP Server on Node n2 (index 1)
  uint16_t port = 9;
  UdpEchoServerHelper echoServer (port);
  ApplicationContainer serverApps = echoServer.Install (nodes.Get (1));
  serverApps.Start (Seconds (1.0));
  serverApps.Stop (Seconds (10.0));

  // 5. Setup UDP Client on Node n1 (index 0)
  // Points to n2's IP address
  UdpEchoClientHelper echoClient (interfaces.GetAddress (1), port);
  echoClient.SetAttribute ("MaxPackets", UintegerValue (5));
  echoClient.SetAttribute ("Interval", TimeValue (Seconds (1.0)));
  echoClient.SetAttribute ("PacketSize", UintegerValue (1024));

  ApplicationContainer clientApps = echoClient.Install (nodes.Get (0));
  clientApps.Start (Seconds (2.0));
  clientApps.Stop (Seconds (10.0));

  // Enable tracing
  p2p.EnablePcapAll ("udp-comm-session5");

  Simulator::Run ();
  Simulator::Destroy ();
  return 0;
}
```


**Technical Insight from MCS-218**

According to your textbook, UDP (User Datagram Protocol) is a connectionless protocol. Unlike the TCP socket we created in Session-3, this UDP client will start sending packets without any "Handshake." If node $n2$ is not ready, the packets will simply be lost.

**Observations for the Lab Record**

* No Handshake: In Wireshark, you will notice that the very first packet sent is a data packet, not a "SYN" packet.
* Header Overhead: UDP has a small 8-byte header compared to TCP’s 20-byte header, making it faster for real-time applications where reliability is less critical than speed.
