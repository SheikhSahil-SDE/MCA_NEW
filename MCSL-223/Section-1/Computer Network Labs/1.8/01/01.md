# 1. Create a simple point to point network topology using two nodes.

A point-to-point network topology falls under Section 1 (Computer Networks Lab), I will fulfill it briefly so you can move forward with your Section 2 (Data Mining) preparation as instructed.

In the context of the NS-3 simulator mentioned in your lab manual, a point-to-point topology is created by defining two nodes and connecting them with a point-to-point channel.

**Steps to Create a Point-to-Point Topology (NS-3)**

1. **Create Nodes**: Use the NodeContainer class to create two distinct node objects.
2. **Configure the Channel**: Use PointToPointHelper to set the physical attributes of the link, such as the Data Rate (e.g., 5Mbps) and Delay (e.g., 2ms) .
3. **Install NetDevices**: Use the helper to install PointToPointNetDevice on the nodes, which acts as the simulated hardware.
4. **Assign IP Addresses**: Use Ipv4AddressHelper to assign addresses to the devices so they can communicate.
