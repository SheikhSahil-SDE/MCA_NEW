Configuring a point-to-point network and use an application that sends data at a constant bit rate (CBR). In NS-3, this is typically done using the OnOffApplication.  
Step-by-Step Instructions
Define Nodes: Create two nodes to act as the UDP Client and UDP Server.  
Configure the Link: Set up a point-to-point channel with specific bandwidth (e.g., 5Mbps) and delay (e.g., 2ms).  
Install the Stack: Use the InternetStackHelper to add TCP/IP capabilities to both nodes.  
Setup the Server (Receiver): Install a PacketSink on the server node. This application "sinks" (receives) the incoming data stream on a specific port.  
Setup the Client (Sender): Install an OnOffApplication on the client node.
Set the "DataRate" attribute to your required fixed rate (e.g., "512kb/s").  
Configure it to use UdpSocketFactory for UDP communication.  

Run and Trace: Enable PCAP tracing to capture the packets for verification in Wireshark, then start the simulation.  

**C++ Code Implementation**
Save this code as udp_fixed_rate.cc in your scratch folder.


```c++```
```
#include "ns3/core-module.h"
#include "ns3/network-module.h"
#include "ns3/internet-module.h"
#include "ns3/point-to-point-module.h"
#include "ns3/applications-module.h"

using namespace ns3;

int main (int argc, char *argv[])
{
  [span_11](start_span)// Create 2 nodes[span_11](end_span)
  NodeContainer nodes;
  nodes.Create (2);

  [span_12](start_span)// Setup Point-to-Point link[span_12](end_span)
  PointToPointHelper p2p;
  p2p.SetDeviceAttribute ("DataRate", StringValue ("5Mbps"));
  p2p.SetChannelAttribute ("Delay", StringValue ("2ms"));

  NetDeviceContainer devices = p2p.Install (nodes);

  [span_13](start_span)// Install Internet Stack[span_13](end_span)
  InternetStackHelper stack;
  stack.Install (nodes);

  Ipv4AddressHelper address;
  address.SetBase ("192.168.1.0", "255.255.255.0");
  Ipv4InterfaceContainer interfaces = address.Assign (devices);

  uint16_t port = 9; [span_14](start_span)// Discard port[span_14](end_span)

  [span_15](start_span)// SERVER: PacketSink to receive UDP at the Server (Node 1)[span_15](end_span)
  PacketSinkHelper sink ("ns3::UdpSocketFactory", 
                         Address (InetSocketAddress (Ipv4Address::GetAny (), port)));
  ApplicationContainer serverApp = sink.Install (nodes.Get (1));
  serverApp.Start (Seconds (1.0));
  serverApp.Stop (Seconds (10.0));

  [span_16](start_span)// CLIENT: OnOffApplication to send UDP at a FIXED rate from Client (Node 0)[span_16](end_span)
  OnOffHelper client ("ns3::UdpSocketFactory", 
                      Address (InetSocketAddress (interfaces.GetAddress (1), port)));
  
  [span_17](start_span)// Set the Fixed Data Rate here[span_17](end_span)
  client.SetAttribute ("DataRate", DataRateValue (DataRate ("512kb/s")));
  client.SetAttribute ("PacketSize", UintegerValue (1024));

  ApplicationContainer clientApp = client.Install (nodes.Get (0));
  clientApp.Start (Seconds (2.0));
  clientApp.Stop (Seconds (10.0));

  [span_18](start_span)// Enable PCAP Tracing for Wireshark analysis[span_18](end_span)
  p2p.EnablePcapAll ("udp-fixed-rate");

  Simulator::Run ();
  Simulator::Destroy ();
  return 0;
}

```
