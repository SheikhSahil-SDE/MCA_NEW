

We will configure a wireless ad-hoc network where two nodes are positioned at specific coordinates in a three-dimensional (3D) space.
​In previous sessions, we often used 2D grids. Moving to a 3D plane allows you to simulate scenarios like communication between nodes at different altitudes or floor levels.

**​Step-by-Step Instructions**

* ​Nodes: Create two nodes using a NodeContainer.
​Wireless PHY and MAC: Configure the wireless physical layer and set the MAC layer to Ad-hoc mode.
​3.D Mobility Configuration: Use the MobilityHelper with a ConstantPositionMobilityModel. Instead of a random walk, you will manually define the (X, Y, Z) coordinates for each node.
​Fixed Distance: Use a ListPositionAllocator to assign specific Vector coordinates. The distance between them can be calculated using the 3D distance formula: d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}.
​Simulation: Install the internet stack and run the simulation to verify connectivity at that specific 3D distance.


**​C++ Code Implementation**
​Save this code as wireless_3d_adhoc.cc in your scratch folder.

```c++```
```
#include "ns3/core-module.h"
#include "ns3/network-module.h"
#include "ns3/mobility-module.h"
#include "ns3/wifi-module.h"
#include "ns3/internet-module.h"

using namespace ns3;

int main (int argc, char *argv[])
{
  // 1. Create 2 Nodes
  NodeContainer nodes;
  nodes.Create (2);

  // 2. Setup Wireless Channel and Physical Layer
  YansWifiChannelHelper wifiChannel = YansWifiChannelHelper::Default ();
  YansWifiPhyHelper wifiPhy;
  wifiPhy.SetChannel (wifiChannel.Create ());

  // 3. Setup Wifi and MAC (Ad-hoc Mode)
  WifiHelper wifi;
  wifi.SetStandard (WIFI_STANDARD_80211b);
  
  WifiMacHelper wifiMac;
  wifiMac.SetType ("ns3::AdhocWifiMac");

  NetDeviceContainer devices = wifi.Install (wifiPhy, wifiMac, nodes);

  // 4. SETUP 3D MOBILITY (Fixed Positions)
  MobilityHelper mobility;
  Ptr<ListPositionAllocator> positionAlloc = CreateObject<ListPositionAllocator> ();
  
  // Node 0 at Origin (0,0,0)
  positionAlloc->Add (Vector (0.0, 0.0, 0.0)); 
  
  // Node 1 at a fixed 3D coordinate (e.g., 10m on X, 10m on Y, 10m on Z)
  // Distance = sqrt(10^2 + 10^2 + 10^2) ≈ 17.32 meters
  positionAlloc->Add (Vector (10.0, 10.0, 10.0)); 

  mobility.SetPositionAllocator (positionAlloc);
  mobility.SetMobilityModel ("ns3::ConstantPositionMobilityModel");
  mobility.Install (nodes);

  // 5. Install Internet Stack
  InternetStackHelper stack;
  stack.Install (nodes);

  Ipv4AddressHelper address;
  address.SetBase ("10.1.1.0", "255.255.255.0");
  address.Assign (devices);

  // Enable PCAP for tracing
  wifiPhy.EnablePcapAll ("wireless-3d-adhoc");

  Simulator::Stop (Seconds (5.0));
  Simulator::Run ();
  Simulator::Destroy ();

  return 0;
}
```
**Observations for the Lab Record**

* Coordinate Representation: Note that in the Vector(x, y, z) function, the third parameter represents the altitude or height. In your code, Vector(10.0, 10.0, 10.0) places the second node 10 units high.
* Propagation Loss: In a 3D plane, the distance is greater than if the nodes were on the same 2D level (e.g., just x=10, y=10). As distance increases in 3D space, the signal strength (RSSI) in your .pcap traces will decrease accordingly.
* Constant Position: Since we used the ConstantPositionMobilityModel, the nodes will not move during the simulation, keeping the throughput stable.
