# 14. Install UDP server and Client at these two nodes.

To install a UDP server and client on a two-node wireless ad-hoc network in NS-3, you use the UdpEchoServerHelper and UdpEchoClientHelper classes. These applications allow you to generate and receive traffic to verify connectivity and measure network performance.


**Step-by-Step Implementation**

* Define the Port: Select a port number for the service (e.g., port 9).
Configure the Server: Install the UdpEchoServerHelper on the destination node.
* Configure the Client: Install the UdpEchoClientHelper on the source node, ensuring the remote address matches the server's IP.
* Set Attributes: Define the packet size, maximum packets, and the interval between transmissions.

**C++ Code Snippet**

This snippet demonstrates how to add the UDP applications to an existing two-node setup.

```c++```
```
// 1. Setup UDP Server on Node 1 (n2)
uint16_t port = 9;
UdpEchoServerHelper echoServer (port);

ApplicationContainer serverApps = echoServer.Install (nodes.Get (1));
serverApps.Start (Seconds (1.0));
serverApps.Stop (Seconds (10.0));

// 2. Setup UDP Client on Node 0 (n1)
// The client must point to the IP address of Node 1
UdpEchoClientHelper echoClient (interfaces.GetAddress (1), port);
echoClient.SetAttribute ("MaxPackets", UintegerValue (5));
echoClient.SetAttribute ("Interval", TimeValue (Seconds (1.0)));
echoClient.SetAttribute ("PacketSize", UintegerValue (1024));

ApplicationContainer clientApps = echoClient.Install (nodes.Get (0));
clientApps.Start (Seconds (2.0));
clientApps.Stop (Seconds (10.0));

// 3. Enable PCAP Tracing
// This generates a .pcap file for analysis in Wireshark
wifiPhy.EnablePcapAll ("wireless-udp-task14");

```

**Verification and Analysis**

* Terminal Output: Upon running the simulation, the terminal will display "Sent 1024 bytes" from the client and "Received 1024 bytes" at the server.
* Packet Analysis: The generated .pcap file can be opened in Wireshark. Since the nodes are in a 3D plane, the "Radio Tap Header" will show the signal strength (RSSI) relative to the 3D distance between the coordinates.
* Latency Monitoring: Because UDP is connectionless, there is no handshake. You can observe the round-trip time (RTT) by comparing the time the echo request was sent versus when the echo reply was received.
