This task is the culmination of the dumbbell topology exercises where you monitor how the two TCP flows interact.  
Step-by-Step Instructions
Execute the Script: Run your compiled script from the terminal. As the simulation runs, NS-3 will generate trace files.  

Command: ```./waf --run scratch/tcp_dumbbell_complete```

Monitor Terminal Output: The PacketSink applications will print the total number of bytes received at each server once the simulation completes.  
Analyze PCAP Files: Open the generated .pcap files in Wireshark. You can filter by IP address (e.g., ip.addr == 10.1.1.1) to see the specific flow from Client 0.  
ASCII Trace Analysis: Check the .tr (ASCII) file for a text-based log of every "enqueue," "dequeue," and "drop" event at the bottleneck link.  
C++ Code for Tracing and Execution
Ensure these lines are at the end of your script before Simulator::Run() to capture the packet flow [cite: 7, 229-231].  

```c++```
```
// --- TASK 7: MONITORING AND TRACING ---

// 1. Enable ASCII Tracing (Text-based log)
AsciiTraceHelper ascii;
p2p.EnableAsciiAll(ascii.CreateFileStream("dumbbell-packet-flow.tr"));

// 2. Enable PCAP Tracing (For Wireshark visualization)
// This captures traffic on all interfaces in the dumbbell
p2p.EnablePcapAll("dumbbell-packet-flow", false);

NS_LOG_INFO("Running Simulation...");
Simulator::Run();
Simulator::Destroy();
NS_LOG_INFO("Simulation Done.");

```
**What to Observe in the Packet Flow**

* Flow Competition: Observe how the sequence numbers for both TCP flows advance. [cite_start]When the second flow starts, you may see the "Window Size" of the first flow decrease as it adjusts to the shared bottleneck [cite: 7, 147-148].  
* Bottleneck Congestion: Look for "TCP Retransmissions" or "Duplicate ACKs" in Wireshark. [cite_start]These indicate that the 1Mbps bridge is saturated and packets are being dropped or delayed [cite: 7, 146-149].  
* [cite_start]Throughput Calculation: Use the total bytes received (shown in the terminal) divided by the simulation time (10 seconds) to calculate the actual average throughput for each flow.
