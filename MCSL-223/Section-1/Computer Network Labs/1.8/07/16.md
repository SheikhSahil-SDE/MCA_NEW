

We must construct a 4-node network using NS-3. The requirement is to have four nodes supporting two TCP client-server pairs and two UDP client-server pairs simultaneously.  
​A CSMA (Carrier Sense Multiple Access) bus topology is the most efficient way to connect 4 nodes for this task, as it allows all nodes to communicate on a shared medium, facilitating multiple overlapping traffic flows [cite: 119, 212-213].  

**​Step-by-Step Instructions**

* ​[cite_start]Topology Creation: Create a NodeContainer with 4 nodes (Node 0 to Node 3).  
* ​Channel Setup: Use CsmaHelper to define the data rate (e.g., 5Mbps) and delay (e.g., 2ms) for the shared bus [cite: 219-220].  
* ​[cite_start]Protocol Stack: Install the InternetStackHelper on all nodes to enable TCP/IP.  
* ​IP Addressing: Assign a single subnet (e.g., 10.1.1.0/24) to the entire CSMA network [cite: 224-225].  
* ​[cite_start]Traffic Configuration: * TCP Pairs: Setup two BulkSendApplication instances (Clients) and two PacketSink instances (Servers) using TcpSocketFactory [cite: 133-134].  
   * ​[cite_start]UDP Pairs: Setup two OnOffApplication instances (Clients) and two PacketSink instances (Servers) using UdpSocketFactory.  
* ​Simulation: Run the script and enable PCAP tracing to verify the four distinct traffic flows in Wireshark [cite: 75, 230-231].  

**​C++ Code Implementation**
​Save this code as session7_multi_flow.cc in your scratch folder.  


```c++```
```
#include "ns3/core-module.h"
#include "ns3/network-module.h"
#include "ns3/csma-module.h"
#include "ns3/internet-module.h"
#include "ns3/applications-module.h"

using namespace ns3;

int main (int argc, char *argv[])
{
  // 1. Create 4 Nodes
  NodeContainer nodes;
  nodes.Create (4);

  // 2. Setup CSMA Bus Topology
  CsmaHelper csma;
  csma.SetChannelAttribute ("DataRate", StringValue ("5Mbps"));
  csma.SetChannelAttribute ("Delay", StringValue ("2ms"));
  NetDeviceContainer devices = csma.Install (nodes);

  // 3. Install Internet Stack
  InternetStackHelper stack;
  stack.Install (nodes);

  Ipv4AddressHelper address;
  address.SetBase ("10.1.1.0", "255.255.255.0");
  Ipv4InterfaceContainer interfaces = address.Assign (devices);

  // --- TRAFFIC SETUP ---
  uint16_t tcpPort1 = 8080, tcpPort2 = 8081;
  uint16_t udpPort1 = 9090, udpPort2 = 9091;

  // 4. TCP PAIR 1: Node 0 (Client) -> Node 1 (Server)
  PacketSinkHelper tcpSink1 ("ns3::TcpSocketFactory", InetSocketAddress (Ipv4Address::GetAny (), tcpPort1));
  ApplicationContainer sinkApp1 = tcpSink1.Install (nodes.Get (1));
  sinkApp1.Start (Seconds (1.0));

  BulkSendHelper tcpSource1 ("ns3::TcpSocketFactory", InetSocketAddress (interfaces.GetAddress (1), tcpPort1));
  ApplicationContainer sourceApp1 = tcpSource1.Install (nodes.Get (0));
  sourceApp1.Start (Seconds (2.0));

  // 5. TCP PAIR 2: Node 2 (Client) -> Node 3 (Server)
  PacketSinkHelper tcpSink2 ("ns3::TcpSocketFactory", InetSocketAddress (Ipv4Address::GetAny (), tcpPort2));
  ApplicationContainer sinkApp2 = tcpSink2.Install (nodes.Get (3));
  sinkApp2.Start (Seconds (1.0));

  BulkSendHelper tcpSource2 ("ns3::TcpSocketFactory", InetSocketAddress (interfaces.GetAddress (3), tcpPort2));
  ApplicationContainer sourceApp2 = tcpSource2.Install (nodes.Get (2));
  sourceApp2.Start (Seconds (2.5));

  // 6. UDP PAIR 1: Node 1 (Client) -> Node 0 (Server)
  PacketSinkHelper udpSink1 ("ns3::UdpSocketFactory", InetSocketAddress (Ipv4Address::GetAny (), udpPort1));
  ApplicationContainer sinkApp3 = udpSink1.Install (nodes.Get (0));
  sinkApp3.Start (Seconds (1.0));

  OnOffHelper udpSource1 ("ns3::UdpSocketFactory", InetSocketAddress (interfaces.GetAddress (0), udpPort1));
  udpSource1.SetAttribute ("DataRate", StringValue ("500kbps"));
  ApplicationContainer sourceApp3 = udpSource1.Install (nodes.Get (1));
  sourceApp3.Start (Seconds (3.0));

  // 7. UDP PAIR 2: Node 3 (Client) -> Node 2 (Server)
  PacketSinkHelper udpSink2 ("ns3::UdpSocketFactory", InetSocketAddress (Ipv4Address::GetAny (), udpPort2));
  ApplicationContainer sinkApp4 = udpSink2.Install (nodes.Get (2));
  sinkApp4.Start (Seconds (1.0));

  OnOffHelper udpSource2 ("ns3::UdpSocketFactory", InetSocketAddress (interfaces.GetAddress (2), udpPort2));
  udpSource2.SetAttribute ("DataRate", StringValue ("500kbps"));
  ApplicationContainer sourceApp4 = udpSource2.Install (nodes.Get (3));
  sourceApp4.Start (Seconds (3.5));

  // Enable Tracing
  csma.EnablePcapAll ("session7-task16");

  Simulator::Stop (Seconds (10.0));
  Simulator::Run ();
  Simulator::Destroy ();
  return 0;
}

```
**Observations for the Lab Record**

* Concurrency: Notice the staggered start times (2.0s, 2.5s, 3.0s, 3.5s). This allows you to see each flow beginning its transmission in the trace file.  
* Flow Types: In Wireshark, you can filter by tcp or udp to see the distinct headers for each pair. Note the 20-byte TCP header versus the 8-byte UDP header.  
* Shared Medium: Since all nodes are on one CSMA bus, they compete for the 5Mbps bandwidth. [cite_start]If the combined data rates exceed this, you will observe "Collisions" or increased "Delay".
