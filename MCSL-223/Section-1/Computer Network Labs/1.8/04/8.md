# 8. Take three nodes n1, n2 and n3 and create a wireless mobile ad-hoc network.


I will shift from the wired point-to-point links of previous sessions to a Wireless Mobile Ad-hoc Network (MANET).

In this setup, nodes $n1$, $n2$, and $n3$ communicate without a central Access Point. This requires configuring the Wireless Physical (Phy) layer, 
the MAC layer for Ad-hoc mode, and a Mobility Model to simulate their movement.

**Step-by-Step Instructions**

1. Node Creation: Define a NodeContainer and create 3 nodes.
2. Wireless Channel & PHY: Use YansWifiChannelHelper and Yans3. WifiPhyHelper to establish the wireless medium.
3. Wifi Helper & MAC: Set the standard (e.g., 802.11b) and configure the MAC layer specifically to AdhocWifiMac .
4. Mobility Model: Use MobilityHelper to assign positions. To make it "mobile," use a model like RandomWalk2dMobilityModel.
5. Internet Stack: Install the standard network stack on all nodes and assign IP addresses in a single subnet (e.g., 10.1.1.0/24).
  
C++ Code Implementation

Save this code as manet_base.cc in your scratch folder.

```C++```
```
#include "ns3/core-module.h"
#include "ns3/network-module.h"
#include "ns3/mobility-module.h"
#include "ns3/wifi-module.h"
#include "ns3/internet-module.h"

using namespace ns3;

int main (int argc, char *argv[])
{
  // 1. Create Nodes
  NodeContainer nodes;
  nodes.Create (3);

  // 2. Setup Wireless Physical Layer and Channel
  YansWifiChannelHelper wifiChannel = YansWifiChannelHelper::Default ();
  YansWifiPhyHelper wifiPhy;
  wifiPhy.SetChannel (wifiChannel.Create ());

  // 3. Setup Wifi and MAC (Ad-hoc Mode)
  WifiHelper wifi;
  wifi.SetStandard (WIFI_STANDARD_80211b);
  
  WifiMacHelper wifiMac;
  wifiMac.SetType ("ns3::AdhocWifiMac");

  NetDeviceContainer devices = wifi.Install (wifiPhy, wifiMac, nodes);

  // 4. Setup Mobility (Initial positions and movement)
  MobilityHelper mobility;
  // Set initial 2D positions in a grid
  mobility.SetPositionAllocator ("ns3::GridPositionAllocator",
                                 "MinX", DoubleValue (0.0),
                                 "MinY", DoubleValue (0.0),
                                 "DeltaX", DoubleValue (5.0),
                                 "DeltaY", DoubleValue (10.0),
                                 "GridWidth", UintegerValue (3),
                                 "LayoutType", StringValue ("RowFirst"));

  // Assign movement model: Random Walk within a 50x50 area
  mobility.SetMobilityModel ("ns3::RandomWalk2dMobilityModel",
                             "Bounds", RectangleValue (Rectangle (-50, 50, -50, 50)));
  mobility.Install (nodes);

  // 5. Install Internet Stack and Assign IPs
  InternetStackHelper stack;
  stack.Install (nodes);

  Ipv4AddressHelper address;
  address.SetBase ("10.1.1.0", "255.255.255.0");
  address.Assign (devices);

  // 6. Enable Tracing for Session Records
  wifiPhy.EnablePcapAll ("manet-session4");

  Simulator::Stop (Seconds (10.0));
  Simulator::Run ();
  Simulator::Destroy ();

  return 0;
}
```

Key Observations for Your Lab Record

* Ad-hoc Configuration: Note that we use AdhocWifiMac instead of StaWifiMac or ApWifiMac. This allows nodes to communicate peer-to-peer.
* Dynamic Topology: Unlike your previous static labs, the distance between $n1$, $n2$, and $n3$ changes every second due to the RandomWalk2d model.
* Connectivity: At some points in the simulation, a node might move too far away and lose connection, which you can verify by checking the signal strength in the generated .pcap traces.
